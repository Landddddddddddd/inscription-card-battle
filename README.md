# 邪刻 · 本地联机版

一个**可本地联机**的《邪刻》——灵感来自《邪恶铭刻》(Inscryption) 风格的卡牌对战游戏。美术参考原作第二章的**像素风**，卡牌数值**严格遵循原版**（攻击/生命/费用/特性）。当前版本支持：

- 🖥️ **单机模式**：对战内置 AI
- 📡 **本地联机**：同一局域网内两人对战（房主开服，好友加入）
- 🎓 **新手教程**：分步引导（放牌 / 祭品 / 结束回合 / 攻击天平）
- 🃏 忠实卡组、特性（飞行 / 连击 / 毒触 / 尖刺 / 不死 / 断尾 / 头狼 / 易碎）与天平胜负机制

> 线上联机（跨公网）为后续版本，当前仅局域网 / 本机。

---

## 快速开始

需要 **Node.js ≥ 18**（无需安装任何 npm 依赖，服务器零依赖）。

```bash
# 在项目根目录
npm start
# 或
node server.js
```

启动后终端会打印本机与局域网地址，例如：

```
本机访问 : http://localhost:3000
局域网访问: http://192.168.1.23:3000
```

用浏览器打开 `http://localhost:3000`（局域网内其他电脑打开房主的局域网 IP 地址）。

## 各模式使用说明

### 单机模式
菜单点「单机模式」即可，你执 A 方，电脑执 B 方。轮到你时操作，结束回合后电脑自动行动。

### 新手教程
菜单点「新手教程」，按弹窗提示逐步操作。教程结束后可继续自由练习。

### 本地联机（LAN）
1. **房主**：点「创建房间」，记下房间号，把本机地址和房间号发给好友。
2. **好友**：在菜单「房间号」输入框填入房间号，点「加入房间」。
3. 双方连接后自动开始，轮到谁谁操作，状态通过服务器实时同步。

> 联机采用「服务器权威 + SSE 推送」：房主运行 `node server.js` 即同时充当服务器；所有逻辑在服务端校验，客户端只负责渲染与发送意图，杜绝作弊。

## 玩法速览

- **资源**：血肉（献祭单位获得）、骸骨（单位死亡获得）、能量（每回合 +1）。召唤卡牌消耗对应资源。
- **场地**：4 列 × 双方各一行。每列己方最多放 1 个单位。
- **特性**：
  - 飞行：越过地面阻挡直击天平，仅被飞行单位挡。
  - 连击：每次攻击造成两次伤害。
  - 毒触 / 尖刺：攻击或挨打时额外伤害。
  - 不死：首次死亡回手牌。
  - 断尾：死亡时获得一只松鼠。
  - 头狼：相邻友方攻击 +1。
  - 易碎：回合结束时死亡。
- **胜负**：每回合结束发动攻击——同列有敌人则交战，否则攻击对方天平。把天平指针压到己方一端（累计 6 点未阻挡攻击）即获胜。

## 项目结构

```
server.js              零依赖 Node 服务器（静态资源 + SSE + REST 动作，权威游戏逻辑）
public/
  index.html           页面骨架
  css/style.css        像素风样式
  js/
    constants.js       卡牌 / 特性 / 牌组定义（Node 与浏览器共用）
    engine.js          纯游戏逻辑（Node 与浏览器共用，权威规则）
    ai.js              单机 AI
    network.js         LAN 客户端（EventSource + fetch）
    ui.js              渲染
    main.js            应用控制（菜单 / 单机 / 联机 / 教程）
```
